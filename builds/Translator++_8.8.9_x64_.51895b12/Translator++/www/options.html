Ruby Text

Ruby text (also called furigana) consists of small characters placed above or beside a word to indicate its pronunciation. This setting controls which engine is used to generate ruby characters for preview text.

  • Kuromoji: A Japanese morphological analyzer. Built-in support for Japanese language processing.
  • MeCab: Another Japanese morphological analyzer. Known for its accuracy and speed. Need to install MeCab through 3rd party application installer.
  • WanaKana: A library for converting between Hiragana, Katakana, and Romaji.

Custom escape

All words that match the pattern below will not be translated by machine translators. This section is suitable for hiding tags and scripts from translation engines.
Each entry is a valid javaScript's of regular expression, function, or literal string that separated by a comma.
Custom escape only worked for supported escape algorithm. Hint:You can also ask ChatGPT to generate you regular expression.
Please write the regex pattern along with its modifier.
for example : /(\\[a-zA-Z0-9]+\[.*\])+/gi
Paste your text here to check the pattern. All matched pattern will be highlighted.

Here, you can specify which columns will be included in the project's progress calculation.
