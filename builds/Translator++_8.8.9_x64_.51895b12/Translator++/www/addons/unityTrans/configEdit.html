Service

End Point

Auto translation service to use.

General

Target Language

The language to translate into

Source Language

The original language of the game. "auto" is also supported for some endpoints, but it is generally not recommended

Files

Directory

Directory to search for cached translation files. Can use placeholder: {GameExeName}, {Lang}

Output File

File to insert generated translations into. Can use placeholders: {GameExeName}, {Lang}

Substitution File

File that contains substitution applied before translations. Can use placeholders: {GameExeName}, {Lang}

Preprocessors File

File that contains preprocessors to be applied before sending a text to a translator. Can use placeholders: {GameExeName}, {Lang}

Text Frameworks

Enable/Disable auto translation for Unity's text frameworks.

Behaviour

Max Characters Per Translation

Max characters per text to translate. Max 2500.

Minimum Dialogue Chars

The length of the text for it to be considered a dialogue

Force Split Text After Characters

Split text into multiple lines once the translated text exceeds this number of characters. (0 is no split)

MaxClipboardCopyCharacters

Max number of characters to hook to clipboard at a time

Override Font

Overrides the fonts used for texts when updating text components. NOTE: Only works for UGUI

Override Font TextMeshPro

Overrides the fonts used for texts when updating text components. NOTE: Only works for TextMeshPro

Resize UI Line Spacing Scale

A decimal value that the default line spacing should be scaled by during UI resizing, for example: 0.80. NOTE: Only works for UGUI

Ignore Text Starting With

Indicates that the plugin should ignore any strings starting with certain characters. This is a list seperated by ';'.

GameLog Text Paths

Indicates specific paths for game objects that the game uses as "log components", where it continuously appends or prepends text to. Requires expert knowledge to setup. This is a list seperated by ';'.

Romaji Post Processing

Indicates what type of post processing to do on 'translated' romaji texts. This can be important in certain games because the font used does not support various diacritics properly. This is a list seperated by ';'. Possible values: ["RemoveAllDiacritics", "ReplaceMacronWithCircumflex", "RemoveApostrophes"]

Translation Post Processing

Indicates what type of post processing to do on translated texts (not romaji). Possible values: ["RemoveAllDiacritics", "ReplaceMacronWithCircumflex", "RemoveApostrophes", "ReplaceWideCharacters"]

Blacklisted IMGUI Plugins

If an IMGUI window assembly/class/method name contains any of the strings in this list (case insensitive) that UI will not be translated. Requires MonoMod hooks. This is a list seperated by ';'

Max Text Parser Recursion

Indicates how many levels of recursion are allowed when text is parsed so it can be translated in different parts. This can be used with splitter-regexes in advanced scenarios. The default value of one essentially means that recursion is disabled.

Redirected Resource Detection Strategy

Indicates if and how the plugin should attempt to recognize redirected resources in order to prevent double translations.

Texture

Texture Directory

Directory to dump textures to, and root of directories to load images from. Can use placeholder: {GameExeName}, {Lang}

Texture Hash Generation Strategy

Indicates how the mod identifies pictures through hashes.

Duplicate Texture Names

Indicates specific texture names that are duplicated in the game. List is separated by ';'

Resource Redirector

Preferred Storage Path

Indicates the preferred storage for redirected resources in relation to the Auto Translator. Can use placeholder: {GameExeName}, {Lang}

HTTP

User Agent

Override the user agent used by APIs requiring a user agent

Translation Aggregator

Width

The total width of the translation aggregator window

Height

The width (per translator) of the translation aggregator window.

Enabled Translators

The id's of the translation endpoints that has been enabled in the translation aggregator window. List is separated by ';'
